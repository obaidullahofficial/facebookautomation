Setup Guide

Follow these steps to connect your AI system to Facebook and start publishing Quranic content automatically.

1
🤖 Get Google Gemini API Key (Free)
Go to aistudio.google.com → Sign in with Google → Click "Get API Key" → Create API Key. Free tier gives you 1,500 requests/day — more than enough for daily Islamic posts. Copy and paste the key in Settings → AI Settings.
2
📘 Create a Facebook App
Go to developers.facebook.com → "My Apps" → "Create App" → Select "Business" type → Fill in app name (e.g. "Islamic Posts Bot"). Your app will give you access to the Graph API for publishing posts.
3
🔑 Get Your Page Access Token
In your Facebook App → "Tools" → "Graph API Explorer" → Select your app → Select your Facebook Page from the dropdown → Click "Generate Access Token" → Grant permissions: pages_manage_posts, pages_read_engagement, publish_to_groups. Then use the Token Debugger to extend it to a long-lived token (60 days).
4
🆔 Find Your Facebook Page ID
Go to your Facebook Page → Click "About" → Scroll down to find Page ID. Alternatively, go to facebook.com/your-page-name, then append /?fields=id after your page URL while logged in. Or use the Graph API Explorer: me/accounts
5
⚙️ Configure & Test
Go to Settings → paste your Gemini API Key, Facebook Page ID, and Access Token. Disable "Mock Mode" to enable real publishing. Click "Validate Facebook Connection" to verify everything works. Then click "Generate Now" to create your first Islamic post and approve it!
6
🌙 Done! Enjoy Daily Quranic Posts
Every day at your scheduled time, the system will automatically generate a new Quranic post with Arabic ayat, Urdu tarjuma, tafseer, and a beautiful Islamic image. You'll review it in the Approval Queue and publish with one click. بارک اللہ فیک!
